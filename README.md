# Netflix Landing Page Clone

This repository contains a static Netflix-inspired landing page built using HTML and CSS only. It recreates the look and feel of Netflix's homepage, including the hero section, feature panels, FAQ area, and footer, with a responsive layout for different screen sizes.

## Project overview

- Front-end only project
- No frameworks or JavaScript dependencies
- Designed to mimic the Netflix landing page styling and structure
- Uses external assets and background images similar to the original Netflix UI

## Features

- Hero banner with Netflix-style branding and call-to-action buttons
- Feature sections showcasing streaming benefits
- FAQ-style blocks for content browsing
- Responsive design for desktop, tablet, and mobile screens
- Footer with language selector and navigation links

```text

├── README.md             # Project documentation

```

## Tech stack

- HTML
- CSS

## How to run

1. Clone the repository.
2. Open `index.html` in a browser, or use a local development server such as Live Server in VS Code.
3. The page should render the Netflix-style landing page.

## Notes

- This is a UI clone and practice project, not a functional Netflix application.
- The `extras` folder contains trial and test files used during learning and experimentation.
- Some visuals use Netflix-style external resources to match the original layout.

## Status

The project is a static front-end mockup and is suitable for learning HTML/CSS layout and responsive design.
